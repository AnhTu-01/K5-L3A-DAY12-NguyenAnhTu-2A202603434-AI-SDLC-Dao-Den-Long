# Video demo (< 5 phút)
Đặt file `demo.mp4` ở đây (hoặc đính kèm GitHub Release v1.0.0). Gợi ý kịch bản ~4 phút:
1. (0:00) `npm test` chạy xanh; `npm run proof4` in "TẤT CẢ ĐẠT".
2. (0:40) Chạy headless một Đêm (`node src/headless.js …`) và mở `soak.json`.
3. (1:10) `npm run bench` → `bench.json` (nói rõ máy đang dùng).
4. (1:50) Chơi trực tiếp ~1,5 phút: nhặt đom đóm, thắp đèn, đèn dưới 30 dầu nhấp nháy, châm dầu, Bóng Mực hút dầu, Tỏa Sáng.
5. (3:20) Cài đặt: đổi phím (thử trùng phím), chữ lớn, giảm chuyển động; bảng xếp hạng lưu tên.
6. (4:00) Kết thúc.
